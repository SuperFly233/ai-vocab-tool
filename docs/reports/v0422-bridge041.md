## User Steps and Limits

No normal Lexi helper process was detected at the final local inventory, so the user's installed version cannot be asserted. Download latest ZIP, extract completely into a new directory, start LexiConnect.exe, open connection settings from tray, verify0.4.1, sign in to the same account/register/check Anki, then approve cards in the original website. Anki and Fushi were already running for authorized acceptance; tests ended their own helper, not those apps.

Physical iPhone, real media playback and Anki's own cloud sync are unverified. Actual forced network loss/OS restart were not performed this turn; failure and interrupted operations are covered by isolated regression tests, while actual helper restart was tested. ZIP is unsigned, not an installer or a signed tamper-resistant runtime. No automatic Fushi media import or production vision is implied.
