# v0.43.14 字段操作对齐修复

## 复现与根因

用户截图指出原句、译文标题行编辑按钮漂在中央，AI按钮贴右。之前虽检查截图和交互，却没有把同组按钮的几何关系作为断言；视觉验收遗漏成立。

1440px实际浏览器复现编辑／AI间距269.625px。编辑按钮和后来插入的AI按钮各自设置 `margin-left:auto`，共同分走空白。

## 修复

- 原句和译文标题行共用 `.hp-field-actions` 操作组，整体靠右，两个按钮28px、间距4px、中心对齐。
- AI按钮直接加入操作组，不再独立分配自动边距。未使用配对组件的字段仍保留原有单按钮靠右行为。
- 新增间距0–8px、中心差不超过1px、右边界差不超过1px和等宽断言。原版测试先失败，修复后重跑。
- 本次为既有设计的局部排版修复，不重画布局，不改配对、数据、模型及Bridge协议。

## 验收与发布

- `npm run check`、配对跨页面集成和控件动画套件通过。
- 320／390／768／1024／1440px明暗主题，阅读与原生输入两态的间距／中心／右边界／等宽断言通过；1873px深色补测通过。
- 人工检查 `docs/design/field-actions-v04314-desktop.png` 和 `field-actions-v04314-mobile.png`：两个操作现在集中在同一右侧组，不再漂在正文中间。
- 独立预览 https://d9e69d31.ai-vocab-tool.pages.dev ，1873px实际部署位置及保存／刷新回归通过。资源核对与正式部署结果随后追加。
