# v0.32.1 弹窗关闭规则修补

## 范围

这是行为修补，不重新设计界面，因此沿用上一轮生图参考，不为相同外观另造设计稿。

- 修复 2 组：素材放大未接入外侧空白关闭；场景标题使用 slice(60/80) 硬截断却不显示省略号。复现测试在 Esc 后的遮罩点击处失败；当前 Chromium 的首次 Esc 可以关闭，不能声称已在所有浏览器复现 Esc 失效。
- 优化 2 项：所有原生 dialog 统一 Esc/cancel/主动遮罩关闭，仍委托原有脏草稿保护；最上层优先、按住 Esc 不穿透，底层编辑器/复习/收藏夹焦点处理退让。
- 新增产品功能 0 项。无数据迁移，不修改场景或词条内容，不启用 Anki 云任务。

- 预览内按下拖到外面松开不关闭；Tab 保留在顶层；模拟重复 Esc 不关闭底层。
