# v0.43 staged learning delivery

Approved order: on-site help/install/verification -> screenshot learning ->
Teyvat attribution -> reviewed consolidation -> large storage migration ->
non-destructive media editing -> AI crop. Keep all incomplete stages visible.

## First release:0.43.0

Reference generated and inspected: docs/design/onboarding-v043-reference.png.
Use compact tabs, unframed tutorial rows, actual release metadata and one
bounded callout. Reject the generated logo, invented menu items, fake checksums,
data path and claims of completed connections. Preserve existing logo/Lucide.

Help is accessible from the existing help control and searchable settings.
Four read-only tours highlight stable real controls; examples live in the
callout, never in history/settings/Anki. First prompt asks once per local
account; skip/replay available. Tutorial progress is local and independently
versioned. No model/API/learning writes merely from playback.

Use the existing popover/overlay infrastructure, not a competing tour library.
Handle viewport/safe areas, focus, scroll restoration and account changes.
Never navigate through or close a dirty editor. Tour close consumes only its
own Escape/backdrop; ordinary editor guards remain unchanged.

Install tab reads the verified release manifest and explains Windows helper
vs phone/Mac submission, program vs data paths, official prerequisite links,
manual updates and actual device diagnostics. Download click is not setup
completion. Existing device commands remain authenticated and selected-device
bound; hidden/closed dialogs stop polling, continuation reuses original request.
