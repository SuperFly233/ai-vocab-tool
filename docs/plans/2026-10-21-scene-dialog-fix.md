# v0.31.1 场景弹窗修补

## 修复与优化

- 修复 1 项：全局 `*{margin:0}` 覆盖原生 dialog 的自动外边距，导致关联选择器及其他同源弹窗贴到左上角。恢复学习弹窗与查询确认的 `margin:auto`，素材放大弹窗已有独立居中规则，不重复修改。
- 优化 2 项：关联选择器只滚动列表，搜索与确认区保持可见；其余学习弹窗正文单独限高滚动，空错误区域不占位。
- 新增产品功能 0 项：本轮只修补弹窗，不扩展 Anki 或场景数据逻辑。
