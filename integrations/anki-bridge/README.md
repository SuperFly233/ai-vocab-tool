# Lexi 连接助手 0.4.1

Windows 本地伴侣程序，复用已有 AnkiConnect。不修改 Fushi、既有模板或复习调度，不设置开机自启。

## 当前发布边界

0.4.0 已正式发布，并以实际便携程序通过完整制卡、重复跳过、更新、回执和安全撤销。0.4.1 增加更新引导、实际版本和有时效的诊断；最新正式下载以网站同源 `bridge-release.json` 为准，未验收包不进入下载清单。网页版本与助手版本独立，不要求每次网页升级都重装。

普通启动不自动打开浏览器；从托盘进入连接设置、检查连接、暂停接单或退出。暂停只阻止新任务，已有批次继续处理。有已领取批次时先完成或明确取消，再正常退出或修改连接；取消不删除已写入卡片。基础制卡只要求账号、设备、云任务和 Anki；Fushi 与词典可选。诊断超过120秒需重新检查，心跳不代表 Anki 就绪。

## 手动更新与首次连接

1. 托盘暂停接单，在网页处理已领取批次，然后正常退出旧助手。
2. 下载正式完整 ZIP，解压到新目录，保留 `_internal`，运行 `LexiConnect.exe`；不覆盖运行中的文件。
3. 托盘打开连接设置，核对“本机版本”和“最新正式版”。配置继承 `%LOCALAPPDATA%\LexiAnkiBridge`；凭据仍在系统凭据库，不在程序目录。
4. 登录同一 Lexi 账号，登记电脑，打开 Anki，检查端口与密钥。无需启用 Fushi 才能普通制卡。
5. 回原网页选择词条，核对目标牌库与卡面后确认。手机／Mac 可提交，执行需要 Windows 助手在线。
6. 已是最新版无需重装；先检查电脑、诊断时间和具体失败项。程序不自动安装插件、提权或修改代理、安全软件。

0.3.1 对官方来源返回实施明确的字段与长度校验，不再静默截断原句；兼容网页 v0.36.0 的稳定请求标识、范围选取和来源追踪。原媒体仍需手动补充。本机实际收藏列表为空，真实单句导入不可据模拟验收宣称完成；详细状态见 v0.36.0 发布报告。

生产任务、网页确认、设备请求、自动接单与词典快照迁移已执行。便携程序已通过真实词典查询、选择义项快照、专用牌库写入、重复跳过、更新、回执与安全撤销；生产开放状态以官网与 v0.35.1 阶段报告为准，不能把预览验收或写入成功视为 Anki 自身同步完成。
原 Lexi 网页是唯一学习工作台，本地程序只负责登录此电脑、连接配置、诊断和执行。Fushi 内容在原网页明确选取后导入，不提供第二套本地场景或制卡编辑器；官方列表未提供原媒体时需手动补充。

## 0.3 词典能力

网页在词条内使用“AI 释义／本机词典”切换。安装并启用的词典由接收电脑通过官方 CLI 返回，用户明确查询、勾选后保存独立快照；已有快照可以离线阅读。正文经过锁定的 nh3 0.3.7 净化，网页再次按允许的元素重建，不执行词典脚本、远程样式或资源链接。

制卡时可选择已保存的义项快照，使用独立的 `Lexi Scene v2`。AI 释义、原始输入 Origin、词典正文和词典来源分别保存，不迁移或修改既有 v1/Lapis 卡片。词典原始插图和发音尚未接入，不包含整套 OALDPE 词库。版本 1/2 任务仍兼容，版本 3 任务引用账号隔离的不可变快照。缺失或校验失败的快照阻止确认，不静默丢弃。

## 使用流程

1. 手动运行 Windows 程序，在本地页面独立登录 Lexi。密码仅用于登录，不写日志或配置；刷新令牌与本地密钥保存到 Windows 凭据管理器，不降级明文。
2. 手动启动安装了 AnkiConnect 的 Anki，检查端口与连接。程序仅访问回环地址，不自动安装插件或更改 CORS。
3. 保存电脑名称、连接端口，登记电脑。首次使用专用“Lexi 验收”牌库。
4. 手机或电脑在 Lexi 场景中选择关联词条与释义，提交快照。视频含封面和原文件，不保证各终端能内嵌播放。
5. 电脑自动准备卡片预览，回到原网页的任务窗口选择目标牌库、检查正反面与原字段，并明确确认后写入。换目标或重启恢复任务需重新预览确认；本地没有独立制卡界面。
6. 手机查看逐项回执。写入 Anki 成功不等于 Anki 自身云同步完成。
7. 使用“退出程序”停止本地服务。关闭浏览器窗口本身不会终止服务；未执行任务仍在云端。

## 恢复与撤销

重复任务通过来源键核对已有笔记。写入成功但回执丢失时，重新预览会查找已建卡片，不直接重复创建。
取消只停止剩余项目，不删除已完成内容。撤销需确认；已学习、有后续编辑或来源不匹配的卡片会保留。
用户切换 Anki 配置、Lexi 账号或目标牌库后需要重新预览。没有跨系统绝对“恰好一次”保证。

配置和操作日志位于 Windows 本机用户数据目录，不应上传到 Git。日志含用于安全撤销的卡片字段，不含密码与令牌。
程序仅开放回环 HTTP，随机会话令牌与 Origin/Host 检查保护写入；没有对公网开放本地端口。

## 开发与打包

推荐 Python 3.12.10 或更新的 3.12 修复版。使用 requirements-lock.txt 创建隔离环境，并设置 PYTHONPATH 为 integrations/anki-bridge 后运行 `python -m unittest discover -s integrations/anki-bridge/tests -v`。
SQL/API 测试使用隔离的 PGlite：先在项目 tmp/anki-bridge-qa 安装 @electric-sql/pglite，再运行 `node scripts/check-anki-jobs.cjs`；它不连接生产数据库。
运行 `python integrations/anki-bridge/build.py` 生成目录式 Windows 程序及第三方许可证，构建最多 180 秒。再运行 `verify_package.py`，在 45 秒内检查运行时、证书策略资源、临时数据库、本地 HTTP 与退出，不登录、不读写真实牌库。成功凭据绑定整个运行目录的文件清单与哈希；`package.py` 拒绝变动过的运行目录。PyInstaller 仍保留为构建工具，不将单文件 EXE 作为交付门槛。

便携 ZIP 必须完整解压，保留 EXE 旁的 `_internal` 目录，双击 `LexiConnect.exe`。无须安装 Python；配置和凭据不保存在包内。同一数据目录重复启动退出码为 3，不开启第二个执行器。未代码签名，首次运行可能有系统信誉提示。

诊断支持 `--self-test`；自动化验收可显式使用 `--data-dir`、官方 `--origin`、`--no-browser` 与 `--connection-file`。连接文件仅含本次回环地址与短期控制令牌，退出时删除，不得上传。普通使用无须这些参数，不把密码、登录令牌或 Anki 密钥写入命令行。
PyInstaller 使用其 GPL 加打包例外；FastAPI/keyring 为 MIT，uvicorn/httpx 为 BSD。完整运行依赖许可证随测试包生成；不打包或复制 Anki/Fushi 程序代码。

托盘依赖 pystray 0.19.5 使用 LGPLv3，Pillow 13.0.0 与 six 1.17.0 采用各自许可证，完整文本位于 `licenses/`。未修改的 pystray 源码随包位于 `third-party-source/pystray`，上游为 https://github.com/moses-palmer/pystray/tree/v0.19.5 。替换、调试或修改该库不受本项目额外限制。重新构建时从 https://github.com/SuperFly233/ai-vocab-tool 获取对应发布提交，在独立 Python 3.12 环境安装锁定依赖后，以修改后的 pystray 源码安装覆盖该依赖，再运行本目录的 `build.py`、`verify_package.py` 和 `package.py`；不要直接改动已验收包后继续使用旧校验凭据。

Fushi 官方 CLI 已实现固定路径、只读白名单和超时适配，锁定核查的上游 725fcde6c9a1e2abef8c72009886a4cd66e4751a。网页来源选取、确认与独立场景导入已在验收预览实现；当前官方收藏/暂存列表不返回图片和音频文件，不读取私有数据库来伪装完整支持。所选来源的原始媒体接入仍未完成。不复制 Fushi GPL 程序代码，不消费其原队列。
